## Meaning

explain causes, reasons, grounds

The thing is that my car broke down and I had to come by bus.

Meaning credits: zero

## Examples

### Example 410

「どうした**んです**か」「ちょっと気分が悪い**んです**」

「どうしたんですか」「ちょっときぶんがわるいんです」

en: "What's wrong?" "I don't feel so great"

Credits: Amatuka, TumorsAreGood

### Example 411

「どうして遅れた**んです**か」「...バスが来なかった**んです**。 」

「どうしておくれたんですかバスがこなかったんです。」

en: "why were you late?" "bus didn\`t come."

Credits: Amatuka

### Example 499

行きたい**のですが**、、、（行けない）

いきたいのですが、、、（いけない）

en: I would like to go, but... (i can't)

Credits: dc

### Example 761

確かに違法じゃない**んです**。そんな簡単に儲からないし、絶対に破綻するシステムでありながら、一律に禁止できないから見逃されている**んです**。

たしかにいほうじゃないんです。そんなかんたんにもうからないし、ぜったいにはたんするシステムでありながら、いちりつにきんしできないからみのがされているんです。

en: Certainly it isn't **(that it's)** illegal. But being a system that doesn't easily generate a profit, is sure to go bankrupt, in the same way it's not possible to ban so it's **(that it's)** overlooked.

Credits: Amatuka

### Comment 1 — 誠

〜んですね（確認）seeking affirmations or confirmation or agreement.<br/>e.g. A:「ここで受験を申し込むんですね。」<br/> B:「ええ、ここで申し込んでください。」<br/><br/>疑問詞＋んですか（説明を求める）seeking explanation<br/>e.g. : 「何時ごろ学校に集まるんですか」<br/><br/>どうして〜んですか（理由を聞く）asking reason<br/>e.g.: 「どうして勉強しないんですか」<br/><br/>〜んです(理由を説明する）giving reason(s)<br/>e.g. A:「どうして日本語を勉強しているんですか。」<br/> B:「日本の生活を経験したいんです。」<br/>Here please note that one should never use ので、から、だから、ものだから together with んです. んですhere is giving the reason.And whenever one is asked with んですか, one should reply with んです。<br/><br/>〜んですが、どうしたらいいですか（助言を求めるときの前置き）seeking for suggestions,advice,help<br/>e.g.　荷物が着かないんですが、どうしたらいいですか／どうしたらいいんでしょうか<br/><br/>〜んですが、〜ていただけませんか（依頼するときの前置き）requesting or asking others for a favour.<br/>e.g. 日本語を勉強したいんですが、ラジオを小さくしていただけませんか。
