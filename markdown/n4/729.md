## Meaning

if, when (verb form)

When I wake up

Meaning credits: Amatuka

## Formation

- Verb past た-form + ら

## Examples

## Discussion

### Comment 1 — 誠

〜たら use for：<br/>１．もし(if)<br/>２．〜た後、〜てから、〜たとき(When.../ After...)<br/>３．本当ではないのこと (If (I) was/could/would...., )<br/>４．勧め(advice/suggestions) (Why don't (you/we)...)

### Comment 2 — Amatuka

Formed like the plain past -ta form with ra added.<br/>目覚める (mezameru) -&gt; 目覚めたら (mezametara)

### Comment 3 — Amatuka

'If' type words like もし can be used to make the if/when distinction clear.

### Comment 4 — Miki

#5254 もしまず here is wordy. Also, it is always 読んだら、not 読んたら、.<br/>まず説明書を読んだら、／もし説明書を読んだら、would be better.

### Comment 5 — bi-ru

Note that it is unnatural to use -tara in circumstances in the past, where a volitional element is present. For example, if you wanted to say 'I stayed in an old ryokan when I went to Kyouto':<br/><br/>京都に行ったら、古い旅館に泊まりました<br/><br/>This sentence is unnatural. Using ~tara in the past would only be used for states or circumstances, e.g.<br/><br/>教室に入ったら、小さなネコがいた

### Comment 6 — 誠

Maybe the following would be more natural:<br/>「京都に行ったとき、古い旅館に泊まりました。」<br/>「教室に入ったとき、小さなネコがいた。」

### Comment 7 — Miki

教室に入ったら、小さな猫がいた。is fine enough. You cannot say which is more natural.

### Comment 8 — cacepi

[#5897} Should use the subjunctive mood, not simple past: "If I were a bird..."

### Comment 9 — Miki

そうそう。確か高校の時に、そう習いました。

### Comment 10 — Mukade

Actually, the past tense usage of たら is okay, as long as the second phrase shows an uncontrollable situation.<br/>(BAD) 京都に行ったら、古い旅館に泊まりました。<br/>(GOOD) 先生の説明を聞いたら、すぐ分かった。
