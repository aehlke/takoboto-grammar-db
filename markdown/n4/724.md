## Meaning

but, however

It rained, but everybody enjoyed themselves.

Meaning credits: Amatuka

## Formation

- Sentence 1 + けれども + Sentence 2

## Examples

### Example 862

雨が降っていた**けれども**、みんなは楽しい時を過ごした。

あめがふっていたけれども、みんなはたのしいときをすごした。

en: **Although** it rained, everyone had a good time.

Credits: Amatuka, Omar

### Example 863

お引き受けしたいんです**けれど**・・・

おひきうけしたいんですけれど・・・

en: I'd like to say yes, **but** ...

Credits: Amatuka

### Example 864

彼は１６歳だ**けれど**、両親から独立しています。

かれは１６さいだけれど、りょうしんからどくりつしています。

en: **Though** only 16, he is independent of his parents.

Credits: Amatuka

### Example 6573

彼はあまり勉強しない**けれども**、成績がいい

かれはあまりべんきょうしないけれども、せいせきがいい

en: Although he doesn't study hard, he gets good marks

Credits: blurp76

### Example 8809

遅く起きた**けれども**、授業に間に合えた。

おそくおきたけれども、じゅぎょうにまにあえた。

en: **Even though** I woke up late, I could make it to the class on time.

Credits: 貴博

### Comment 3 — Amatuka

Used to join two sentences.<br/>けれども (most formal) →けれど→けど (least formal)<br/>けど used in speech, not when writing.<br/>Using けれども etc to start a sentence is frowned upon. But, like using 'but' to start a sentence in English, is sometimes done anyway.

### Comment 4 — Amatuka

Verb, i-adjective or the copula should be before けれども.<br/><br/>e.g. 彼は１６歳だけれど、両親から独立しています。

### Comment 5 — Amatuka

In polite/formal use <br/>sentence-A [-masu] けれども sentence-B [-masu] can be used, but <br/>sentence-A [plain] けれど(も) sentence-B [-masu]<br/>is also possible.
