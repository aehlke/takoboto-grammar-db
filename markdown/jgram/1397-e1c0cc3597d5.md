## Meaning

you should これをした方よい

you should do this

## Notes

### 1 — dc

There are various levels of suggesting/asking/telling/ordering someone to do something in japanese, just like in english.<br/>
<br/>
In general order of the strength of the suggestion:<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> = better if/ought to<br/>
it would be better if you do this<br/>
これをした方がよい<br/>
<br/>
it would be better to do it this way<br/>
こいう風にした方がよい<br/>
<br/>
you should exercise more<br/>
もっと運動したほうがいい<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> = should<br/>
You should do this <br/>
あなたはこれをするべきです。<br/>
(it sounds stronger in Japanese, I guess.)<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> = must/have to<br/>
You must do this <br/>
あなたはこれをしなければなりません<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> = neccessary<br/>
it is neccessary that you do this<br/>
これをする必要があります<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> = obligation<br/>
you are obliged <br/>
あなたは。。。する義務があります<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> = required to (formal) eg by law<br/>
it is required to do this (eg by law)<br/>
これをせざるを得ない<br/>
