## Meaning

if

If it's from outside, I don't mind.

## Notes

### 1 — dc

there are a few if/when constructs:<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> is similar to -<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b><br/>
formed with verb-plain form + nara<br/>
　行くなら分かる = if/when you go you will understand<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> is used when the action is expected to happen, rather than use the english 'if' use 'when...' <br/>
formed with verb-plain form + to<br/>
　行かないとまずい = it will be bad if you dont go<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> is used when PEOPLE do the actions or suggesting an action. masu-stem + ba<br/>
　行けばいいよ　= its ok to go<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> is used in the other cases<br/>
　寒かったら行かない = if its cold i won't go<br/>

### 2 — 誠

〜なら：１．もし (if) ;  辞書形 +（の,optional)なら<br/>
<br/>
         2.勧告(advice);  辞書形 + (の,optional)なら<br/>
<br/>
　　　　  3.話題を出す時;  (Speaking of.../ For...) ; 名詞 +（の,optional)なら　 <br/>
<br/>

## Discussion

### 1 — Amatuka

なら is used in the context of suggestions, commands, violitional sentences and such. (One example of each above ;-)

### 2 — Amatuka

Therefore なら can't be used in sentences like the following where no such elements are present.<br/>
(BAD) 冷蔵庫を閉めるなら電気が消えますか。<br/>
(GOOD) 冷蔵庫を閉めると電気が消えますか。<br/>
If(when) you shut the fridge does the light go out?

### 9 — フリザ

「なら」と「たら」の違い<br/>
例：「山田さんが来たら、私は帰ります。」の場合には、<br/>
山田さんが来てから私が帰るという意味であるが、「山田さんが来るなら、私は帰ります。」の場合には、山田さんが来る前に私が帰るという意味になる。<br/>
うふふふ、朝飯前わね＾＾

### 10 — 誠

と can also mean " that..." <br/>
行かないとまずい " It is not good that (I/you/one) don't go"

### 11 — 誠

〜なら／ならば、．．．、although なら is more common and usually, appear in conversations.

### 12 — 誠

One cannot use と(if/once)、with 意志形、命令形、ください、but instead use たら、なら、〜えば according to the respective situations or sentence.

### 13 — 誠

Agree with フリザさん. <br/>
「ここは禁煙です。煙草を吸うなら、外へ出てください。」→　外へ出てから、煙草を吸っては構いません。<br/>
<br/>
「煙草を吸ったら、入ってもいいです。」→　煙草を吸ってから、入っても構いません。
