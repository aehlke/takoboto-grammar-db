## Meaning

your message is that ...

you are coming to tokyo tomorrow,right?

## Notes

### 1 — Ashishjoshi

ということですね.  is an expression for confirming information obtained from another person.<br/>
but two points should be observed while using this expression:-<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE=toiukotodesune#"></a></b> when just confirming a fact.<br/>
     -the content to be confirmed is simply repeated or summarized.<br/>
Ex-(a ) あした 10じ から かいぎ を はじめる と つたえて いただきたいんですが...<br/>
--あした の かいぎ は 10じから という こと です ね.<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE=toiukotodesune#"></a></b>when confirming an action of another person.<br/>
    -if the person is superior or not close  to you,certain words need to be replaced with honorific words.in addition,if the speaker uses the words like 'there',meaning the location of the listner,then it should be replaced with 'here' while confirming.<br/>
<br/>
Ex-(a)あした そちら へ いく と つたえて いただきたいん です が.<br/>
    --あした こちら へ いらっしゃる と いう こと です ね.
