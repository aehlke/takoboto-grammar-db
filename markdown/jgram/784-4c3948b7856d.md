## Meaning

Vte something has been purposely put into a state

The window has been closed.

## Notes

### 1 — kurisutofu

てある only combines with transitive verbs, never intransitive. <br/>
The result of transitive + てある is an intransitive itself.<br/>
<br/>
窓が開いている -&gt; The window is open. (no agent or reason implied)<br/>
<br/>
窓が開けてある -&gt; The window is open (because someone opened it).

### 5 — Tenorikuma

Amatuka is wrong on pronunciation.<br/>
<br/>
窓が開いている -&gt; まどがあいている<br/>
<br/>
As Bi-ru notes, the ている form is resultative for intransitive verbs, but the てある form lets you take a transitive verb and do the same thing.<br/>
<br/>
窓が開いている  -&gt;  The window is open. (no agent or reason implied)<br/>
<br/>
窓が開けてある  -&gt;  The window is open (because someone opened it).

### 6 — tigert

Amatuka`s pronunciation isn`t wrong. 開く　can be pronounced あく　or ひらく　they both mean the same thing. but あく is used for things that swing open and ひらく is used for things that slide open. IE sliding doors, windows, etc...
