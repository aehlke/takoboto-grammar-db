## Meaning

is surely because 〜; not surprising that 〜; It was worth 〜

It is not surprising that the representative flower of Japan is the cherry blossom.

## Notes

### 1 — dc

<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>haaru and <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> are the same, but with the sentence order reversed. <br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b><br/>
その映画は面白かった。Woody Allenが作っただけのことはある。 <br/>
That movie was really interesting. That's what I expect of a Woody Allen film.<br/>
<br/>
<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b><br/>
Woody Allenが作った映画だけあって、面白かった。  <br/>
As I'd expect from a Woody Allen film, that was really interesting.<br/>
<br/>
<br/>
このメロンはおいしい。高かっただけのことはある<br/>
このメロンは高かっただけあって、おいしい<br/>
both meanings are basically:<br/>
as you'd expect for a melon that was so expensive, this is delicious.

### 2 — rubyhatchet

「Ａだけあって・だけに、Ｂ。」＝「Ｂ。Ａだけのことはある。」<br/>
<br/>
You should only use this grammar for positive nuances.<br/>
<br/>
FORMATION;<br/>
Ｖnormal form + だけのことはある<br/>
Ｎ + だけのことはある<br/>
いＡ + だけのことはある<br/>
なＡ + な・だった + だけのことはある

### 3 — rubyhatchet

I changed the entry tag from だけのこと to だけのことはある because they are different. だけのこと was the original intent for this entry, but everyone was using it as an entry for the latter.<br/>
<br/>
This grammar has several meanings depending on your preference or on context. 気を付けてね。
