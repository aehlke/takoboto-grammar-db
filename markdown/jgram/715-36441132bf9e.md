## Meaning

even if

even if you

## Notes

### 1 — rubyhatchet

Using たとえ before ～ても(でも) is simply for stronger emphasis.<br/>
<br/>
たとえ + Ｖて形 + も<br/>
たとえ + いＡて形 + も<br/>
たとえ + なＡ + でも<br/>
たとえ + Ｎ + でも
