## Discussion

### 1 — blabby

There is Kanji for this grammar (宛ら), but it is usually written in hiragana.<br/>
<br/>
For <b><a href="http://jgram.org/pages/viewOne.php?tagE=sanagara#">#</a></b>, "Avoiding the main issue" is the only translation I can come up with for お茶を濁す that doesn't sound awkward. Any better ideas?

### 2 — bamboo4

Something like "muddle along" may be?<br/>
