## Meaning

but

I know him but we've never met.

### 5 — nellyaudrey

as far as i know, ga is more like a "yet" type of but. demo means something closer to "however". And keredemo is closer to "nevertheless".

### 6 — nellyaudrey

oh, i should add that ga typically contrasts between two differing sentences. Like that one above, <br/>
毎日一生懸命に英語を勉強したが、あまり身につかなかった。 <br/>
I studied English very hard every day, but I did not learn a lot.  <br/>
<br/>
a demo sentence would be<br/>
この本はすてきでも買えないだからすぎる高いですよ．<br/>
a keredemo sentece implies that you've done something despite something else. It would be<br/>
この本は高いけれでも買いました．<br/>
<br/>
Feel free to correct any of my mistakes but these are the rules as i learned them.
