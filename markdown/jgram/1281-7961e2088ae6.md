## Meaning

If it wasn't for...

If it wasn't for love...

## Notes

### 1 — LR

<b>Ref <b><a href="http://jgram.org/pages/viewOne.php?tagE=nakushite#">#</a></b></b> Kanzen Master Level 1 - p17 - no.16

### 2 — LR

<b>Ref <b><a href="http://jgram.org/pages/viewOne.php?tagE=nakushite#">#</a></b></b> A Dictionary of Advanced Japanese Grammar p315

### 3 — LR

The use of wa after nakushite indicates that the sentence is a conditional sentence. This means that when a sentence has a conditional meaning, wa is mandatory as shown in  山川教授...<br/>
= perhaps nakushite is "without"<br/>
= perhaps nakushitewa is "if it weren't for" - slightly stronger

## Discussion

### 1 — blabby

I think a good translation for this is "If it wasn't for_,".

### 2 — 誠

I agree that it should be translated as " If it wasn't for...". <br/>
By the way, in ex <b><a href="http://jgram.org/pages/viewOne.php?tagE=nakushite#">#</a></b> the usage of なくして seems strange. Because it sounds strange when translated,<br/>
[ If it wasn't my permission, you should not have done such a thing].<br/>
〜なくして（は）．．．ない where the usage usually comes with<br/>
 "If it wasn't ..., then..(followed usually by sentence stating : can't / doesn't have the potential or possibility to do or have something)"<br/>
<br/>
It should have been :<br/>
「私の許可がなかったら、君はそんなことをすべきではなかったのだが．．．」<br/>
If there wasn't any of my permission, you shouldn't have done such a thing... <br/>
<br/>
<br/>
Or 「私の許可ではなかったら、君はそんなことをすべきではなかったのだが．．．」<br/>
If it wasn't of my permission, you shouldn't have done such a thing.<br/>
<br/>
Or another example for なくして,<br/>
皆さんの協力なくして、そんなに辛い事を解決できないのだ。<br/>
<br/>

### 3 — Miki

As for <b><a href="http://jgram.org/pages/viewOne.php?tagE=nakushite#">#</a></b>, I don't think the Japanese is wrong even if it sounds strange when translated. Please advise a proper translation for it.

### 4 — 誠

ex <b><a href="http://jgram.org/pages/viewOne.php?tagE=nakushite#">#</a></b> would mean that <br/>
if it wasn't of my permission, you shouldn't have done such a thing.<br/>
<br/>
I am actually doubting the usage of なくして in that example,<br/>
not the Japanese.<br/>
Instead I suggest:<br/>
私の許可なくして、君はそんなことを達成するのが無理だ。<br/>
If it wasn't of my permission, it is impossible you could achieve such a thing.<br/>
<br/>
After なくして、 it is natural to be followed by something that one can't achieve or something that is impossible to happen without it.<br/>
<br/>
In <b><a href="http://jgram.org/pages/viewOne.php?tagE=nakushite#">#</a></b>, it is 'shouldn't' instead of 'can't/impossible'<br/>
<br/>
Here are some examples from a book:<br/>
1.彼は、人工呼吸器の助けなくしては一日も生きられない体だ。<br/>
<br/>
2.日々の努力なくして、成功はあり得ない。<br/>
<br/>
3.それは、涙なくしては見られない感動的な映画だった。<br/>
<br/>
４．皆さんの応援なくして、優勝はなっかったと確信致します。<br/>
<br/>
５．苦しい練習なくして、試合に勝つ事はできあないのだ。<br/>
<br/>
６．悲しみなくして、人生の喜ぶを知ることはできない。<br/>
<br/>
７．如何にお金があろうと、育てる者の愛情なくして、子供は幸せになることができない。<br/>
<br/>
There is a difference between 'If it wasn't for...' with 'without'.<br/>

### 5 — 誠

みきさん、<br/>
Below is some explanation from my 先生：<br/>
「私の許可なくして＿＿＿」の文は日本語ではあまり使いませんから、<br/>
正しい文は「私の許可なしで＿＿＿」でしょう。<br/>
or<br/>
「私の許可なしに、______」

### 6 — bamboo

私の許可なくして is perfectly valid in terms of written Japanese. In terms of spoken Japanese, perhaps 私の許可を受けないで would be normal, even though 私の許可なしに would also be acceptable.<br/>
