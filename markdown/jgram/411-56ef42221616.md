## Meaning

but

the training is tough, but it only lasts three months

## Notes

### 1 — khongbietboi

[動・い形・な形・名]の普通形＋といっても　＜sometimes[な形；名]do not use [だ]＞

### 2 — rubyhatchet

FORMATION:<br/>
Ｖ(plain form) + といっても<br/>
いＡ + といっても<br/>
なＡ・Ｎ + といっても<br/>
<br/>
＊何といっても can be translated as "after all."

## Discussion

### 1 — Amatuka

Literally : 'say X but' e.g. "Say it's tough, but because it only lasts three months ..."

### 2 — bamboo4

Cleaned up the examples.

### 3 — rubyhatchet

In the first example, the highlights are positioned wrong. 「大変だといっても3ヶ月間だけですから。」 (It's tough, but it only lasts three months.) The "but" should be highlighted. Also, the given English translation adds too many extras, such as "you can say" and "keep in mind." Those are not present in the Japanese sentence. Also, can we try to remember periods?<br/>
<br/>
Example <b><a href="http://jgram.org/pages/viewOne.php?tagE=toittemo#">#</a></b> is in the wrong grammar entry. It should be in たとえ〜ても, which means "even if." といっても by itself means "yet, however, but." Also, the correct translation is, "Even if I say that there's a convention, I really shouldn't ask them for so much money."<br/>
<br/>
Example <b><a href="http://jgram.org/pages/viewOne.php?tagE=toittemo#">#</a></b>, it should be "I was wrong after all." Example <b><a href="http://jgram.org/pages/viewOne.php?tagE=toittemo#">#</a></b> doesn't have an English translation, which should be "Although there's a garden, it's rather tiny."<br/>
<br/>

### 4 — xabre24

As shown in Example <b><a href="http://jgram.org/pages/viewOne.php?tagE=toittemo#">#</a></b>, another version of 〜と言っても　is 〜と言ったって. This is no less formal and has exactly the same meaning. A less formal and less common version is 〜ったって, which is placed after a plain affirmative verb, eg 帰るったって.<br/>

Or perhaps<br/>
なＡ・Ｎ + (だ)といっても<br/>

### 10 — dekirukana

The translation for ex <b><a href="http://jgram.org/pages/viewOne.php?tagE=toittemo#">#</a></b> was inaccurate. 額（ひたい）in this context means "forehead", not "amount". So you get, "the forehead of a cat", an amusing Japanese way of saying "tiny". "The amount of a cat" makes absolutely no sense. Think harder next time about your translations.

### 11 — jmadsen

I think the Header Meaning should say more than just "but"...the idea I see most often with this is:<br/>
<br/>
A is X, but it is only a little bit X<br/>
<br/>
In other words, the second part serves to deprecate the first part ("We have a garden, but it is only a tiny garden." or "I travel a lot, but only for work ( so it isn't much fun).")
