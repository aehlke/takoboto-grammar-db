## Meaning

can't avoid doing x

i can't not go \[always double-neg\]

## Notes

### 1 — 誠

〜ざるを得ない: 〜したくないが．．．しなければならない

### 2 — rubyhatchet

This is an auxiliiary indicating that there is no other choice but to do something. Possible translations include: cannot help 〜ing; cannot help but; have no choice but to have to.<br/>
<br/>
Ｖneg + ざるを得ない<br/>
Examples: 食べざるを得ない // 行かざるを得ない<br/>
Exception: する -&gt; せざるを得ない

### 3 — rubyhatchet

＊Be very careful as to when you replace one of these phrases with another.<br/>
<br/>
Ｖneg + ざるを得ない : used in a situation where one has no choice but to do something.<br/>
<br/>
Ｖ + しかない : used in a situation where one has no choice but to do something.<br/>
<br/>
Ｖneg + なければならない : used in a situation where one has to do something because s/he has an obligation to do it OR where one has no choice but to do something.<br/>
<br/>
Ｖneg + わけに(は)いかない : used in a situation where one has to do something because s/he has an obligation to do it OR where one has no choice but to do something. It also expresses the unwillingness of the speaker to do Ｖ.

## Discussion

### 1 — Amatuka

Lit (sort of) : Unable to obtain not doing ___

### 2 — Amatuka

Note the verb form 〜ざる is a left over from a classic form that is now pretty much out of general use.  <br/>
(Don't ask me more, please ;-)

### 3 — Amatuka

Hmm, on second thoughts I'm only about 60% sure it's the negative of うる and not the negative of える.  <br/>
<br/>
That word's a pain.

### 4 — Amatuka

Formed from v-nai base + ざるをえない. <br/>
e.g. 行く→行かない→行かざるをえない<br/>
<br/>
Vn = V-nai base

### 5 — pgb

isnt える and うる the same verb in this case?

### 6 — Miki

Please see the comment by bamboo4 in <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>. ざるを得ない is one word and always read as ざるをえない. There is no ざるを得る.

### 7 — bamboo4

ざる is an archaic particle indicating negation. It's root form is ず and it inflects as ず/ざら、ず/ざり、ざる/ぬ、ざれ/ね but its imperative form is ざれ. In tbis manner, it has very unique inflections.<br/>
行かざる means not going, which is denied by えない so that it becomes "not going is not capable," the double negative thus resulting in "I must go."<br/>

### 8 — bamboo4

<b><a href="http://jgram.org/pages/viewOne.php?tagE=zaruwoenai#">#</a></b> is not acceptable. 同情の涙を禁じ得ない would be the correct diction. ざるを得ない is not appropriate so that this example does not belong to this head.

### 9 — 誠

<b><a href="http://jgram.org/pages/viewOne.php?tagE=zaruwoenai#">#</a></b> grammatically is not wrong, but the meaning is very strange. Because 〜ざるを得ない means you have to do 〜even you don't want to, and 禁じる means 抑える or suppress,<br/>
So, 同情の涙を禁じざるを得ない means:<br/>
You have to suppress tears of sympathy, even if you didn't want to (suppress).<br/>
<br/>
Whereas, 同情の涙を禁じ得ない means(which is more natural in this case):<br/>
You couldn't suppress/stop tears of sympathy (of dropping down).同情の涙を抑えることができない <br/>
