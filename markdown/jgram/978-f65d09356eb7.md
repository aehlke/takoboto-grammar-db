## Meaning

in the end,  afterall

in the end, he ended up in jail

### 4 — MightyAtom

Often used with さんざん

### 5 — khyron

According to a native speaker, this grammar adds a negative feeling to the sentence, so either the first part preceding the 挙句 or the following part should have a negative feel to reflect that. <br/>
<br/>
In the example:<br/>
「散々考えた挙げ句その計画を実行にうつした」<br/>
this is equivalent to <br/>
「散々悩んだ挙げ句その計画を実行にうつした」<br/>
in feeling due to the presence of 挙句. <br/>
<br/>
Similarly in another example<br/>
「両親に相談したあげくに、彼と結婚することにした。」<br/>
sounds unnatural, because the decision to marry someone is a positive one. If it was instead <br/>
「両親に相談したあげくに、彼と離婚することにした。」<br/>
then it would sound more natural because divorce has a negative connotation.

### 3 — Amatuka

(n-adv,n-t) Noun-Adverb (a noun that can be used as an adverb) + Noun-timelike (a noun that can be used where a 'time' reference is expected).<br/>
<br/>
Noun use 'ageku no hate' - ageku modifies hate<br/>
'time-like' use 'ageku kare no sasoi wo kotawatte shimatta.' (ageku specifies when 'kare no ...')

### 15 — bamboo4

The use of 折角 in せっかく勉強したので is archaic. Nowadays, people would say 一生懸命 or 頑張って勉強したので. In modern usage, 折角 is used in negative sense, such as 折角勉強したのに落第した (Though or despite the fact that I studied hard, I failed to make the grade)<br/>
