## Meaning

but, however

It rained, but everybody enjoyed themselves.

## Discussion

### 1 — Amatuka

Used to join two sentences.<br/>
けれども (most formal) →けれど→けど (least formal)<br/>
けど used in speech, not when writing.<br/>
Using けれども etc to start a sentence is frowned upon.  But, like using 'but' to start a sentence in English, is sometimes done anyway.

### 2 — Amatuka

Verb, i-adjective or the copula should be before けれども.<br/>
<br/>
e.g. 彼は１６歳<b>だ</b>けれど、両親から独立しています。

### 3 — Amatuka

In polite/formal use <br/>
sentence-A <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> けれども sentence-B <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> can be used, but <br/>
sentence-A <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> けれど(も) sentence-B <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b><br/>
is also possible.
