## Meaning

What

What will you have?

## Notes

### 1 — izumichan31

Use nan before b, p, d, t, n, r, and z. Use nani before all other letters.

### 2 — Rinji\_HalfElf

<b>Nan and Nani</b><br/>
<br/>
Generally nan, or nani is used for which ever flows better.<br/>
However, Nani is used when wanting to be more polite and formal.<br/>
Other situations may require getting a feel for using nan versus nani, or memorization.<br/>
<br/>
In general, if the following word begins with a syllable from the t, n, and d groups. Nan is used.<br/>
<br/>
Common usages:<br/>
Nan is used before particles <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>/の, <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>/で and verb da/desu.<br/>
<br/>
Nani is used Before <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>/か and <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>/に,<br/>
<br/>
If nan was used before ka/か, it would sound like the word nanka, which means "things like" or "something like that" which is also considered rude.<br/>
Nanika is instead used. Both nanka and nanika mean "something", but nanika is polite.<br/>
<br/>
If nan was used in the case of ni/に, it would produce nanni なんに. This　sounds similar to nannimo なんにも, which means "nothing at all". <br/>
Generally mo/も、to indicate nothing, or absence. This could confuse a listener, waiting for a <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> to be uttered.<br/>
<br/>
