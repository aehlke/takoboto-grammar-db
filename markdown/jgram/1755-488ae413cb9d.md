## Meaning

as if; as if ~ were convinced that; as if ~ believed that; as if ~ decided that

Takemoto vented his long held complaints as if he were convinced this was the time to do so

## Notes

### 1 — LR

<b>BE CAREFUL</b> not to confuse ばかりに with とばかりに.<br/>
<strong>ばかりに</strong> is for indicating a single factor that causes a negative situation and is formed <br/>
{VERB-past-tense / いadj. / なadj.stem / NOUN} +ばかりに<br/>
<strong>とばかりに</strong> indicates that s.o does s.t in such a way that s.o. is convinced that something is the case - "思い立ったが吉日とばかりにエアロビクスを始めました。<br/>
I began aerobics believing that the day you think of something is an auspicious day to start it." and is formed<br/>
{direct quotation / indirect quotation / noun} + とばかりに<br/>
See <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>

### 4 — LR

<b>On the difference between <strong>とばかりに</strong> and <strong>と言わんばかりに</strong></b><br/>
<br/>
と言わんばかりに"as if to say", and というように"in such a way that, as if to say" are synonymous with とばかりに and can be used in place of とばかりに in some cases.<br/>
<br/>
However, you can't say と言わんばかりabout yourself: "The fog finally cleared so I ran outside as if to say this is my only chance" would be weird in Japanese (surely you don't need to guess your own thinking), but in this sentence you could use とばかりに and it would be more like "The fog finally cleared so I ran outside as if it was my only chance"<br/>
see <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b>
