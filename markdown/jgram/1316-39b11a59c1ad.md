## Meaning

like,  as if (metaphor)

he looked as if he knew nothing about it

### 8 — ahbonk

According to my Kanzen Master book, the difference between かのようだ and just ようだ is that in the case of かのようだ, it's not actually true but it just seems like it.<br/>
<br/>
So for example, if you see the boss' packed schedule this month, you can't say:<br/>
<br/>
社長は来月忙しいかのようだ。 x Wrong<br/>
社長は来月忙しいようだ。 o Right<br/>
<br/>
Here's the excerpt from the book:<br/>
<br/>
（意味）　実際にはそうではないが、〜のようだ。
