## Meaning

because



## Notes

### 1 — rubyhatchet

「Ａことから、Ｂ」 Ａは、Ｂで言うことの理由・原因・根拠<br/>
「Ａことから、Ｂ」 A is the reason, cause/origin, or basis for B.<br/>
<br/>
Ｖ(plain form) + ことから<br/>
いＡ(reg. form) + ことから<br/>
なＡ + な + ことから // なＡ + だった + ことから<br/>
Ｎ + だった + ことから

### 2 — sureshnihon

ので、「その理由を述べて後ろの文の根拠を示す。」<br/>
Ｖ(plain form) + ことから<br/>
いＡ(reg. form) + ことから<br/>
なＡ + な + ことから // なＡ + だった + ことから<br/>
Ｎ + だった + ことから

## Discussion

### 1 — Miki

These examples are not for this entry if the english is "because". Maybe koto + "kara-2"?

### 2 — blabby

There is a difference between ことから and ことだから. <br/>
ことから = Because<br/>
ことだから = "It's always like this so.."<br/>
Maybe somebody can find a better translation for ことだから.
