## Meaning

as soon/early as possible

I'd like to meet as soon as possible

## Notes

### 1 — dc

dekirudake + adverb means "as much as (adverb)".<br/>
its used as an almost set phrase with 'hayaku':early/fast.<br/>
dekirudake hayaku: as quickly/soon/early as possible.

## Discussion

### 1 — dc

is this used with the leading verb being a potential?<br/>
会えるだけ早く<br/>
meet as soon as possible<br/>
<br/>
作れるだけ早く<br/>
make as soon as possible<br/>
<br/>
食べられるだけ早く<br/>
eat as quickly as possible

### 2 — dc

can it be used with negatives?<br/>
<br/>
できるだけ遅く<br/>
as slowly/late as possible?

### 3 — Miki

If you use the verb twice like this, it is possible. 会えるだけ早く会う。

### 4 — Miki

With negative, you can use it.　<br/>
できるだけ遅く、来てください。<br/>
Please come as late as possible.
