## Meaning

doesn't it seem ~ ?

seems like it will rain?

## Examples

### 487 — Amatuka

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ雨が降るようではないか">
				雨が降る<strong>ようではないか</strong><strong></strong></a> <br/>
		seems like its going to rain 
		<strong>doesn't it? </strong>

### 897 — Amatuka

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ空にのびる枝が我々を導いてくれてるようではないか。">
				空にのびる枝が我々を導いてくれてる<strong>ようではないか</strong>。<strong></strong></a> <br/>
<strong>Doesn't it seem as if </strong>
		the branches extending into the sky are guiding us?

### 4767 — Miki

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ動いているのに、進んでいないようではないか。">
				動いているのに、進んでいない<strong>ようではないか。</strong><strong></strong></a> <br/>
		Een though you're moving 
		<strong>it doesn't seems as if </strong>
		you're going anywhere.

## Discussion

### 1 — Miki

This sentence is not so natural.<br/>
I would say 雨が降り_そう_ではないか。<br/>
ではないか can be replaced by じゃないか。(conv)<br/>

### 2 — Amatuka

Doesn't seem to be very common usage.

### 3 — Amatuka

Is that example any better?

### 4 — Miki

With this example, it is difficult to make it any better to suit the entry.

### 5 — bamboo4

ようではないか is a book Japanese. It is hardly used in conversation.
