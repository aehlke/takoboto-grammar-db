## Meaning

Adds emphasis - sentence ending particle; Emphasizes personal desires 自分のしたいことや欲しいものなど

Won't it be great if we can go fishing tomorrow?

## Notes

### 1 — jeina419

hora! watashi no aibou no aidea wa ii naa?<br/>
trans:see here! isnt my partner's idea great?

### 2 — tigert

〜なぁ　Emphasizes the speakers personal feelings as supposed to 〜ね which seeks confirmation from the listener.<br/>
<br/>
明日は晴といいなぁ　<br/>
it would be nice if it was sunny tomorrow.<br/>
明日は晴といいですね<br/>
wouldn`t it be nice if it was sunny tomorrow.

## Discussion

### 1 — Amatuka

Short and long なあ versions, both mean the same thing.

### 2 — Miki

Won't it be gret if (we) can fish tomorrow. ではありませんか？　釣る=to fish、釣りに行く=to go fishing

### 3 — Amatuka

Hmm, true.  But you can't <b>fish</b> without <b>going to fish</b> so it's not such a big difference.

### 4 — Amatuka

"going to fish" is probably rather more common - but both are OK so I'll change it as you suggest.
