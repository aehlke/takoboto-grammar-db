## Discussion

### 1 — bamboo4

ように has a meaning of "to do" or "so that one can do" which I guess would include "become." The first example can literally be translated as "For that reason, I want to do so that I can speak better English." <br/>
<br/>
My second example follows that vein.<br/>

### 2 — Naino

Um, this might be of use but it's especially for the youni NARU -sentence pattern. But it said in the comments of the "youninaru" that this grammar entry would do, so...One of the possible usages of ように:<br/>
<br/>
ようになる expresses a change that takes place gradually.<br/>
<br/>
With verbs:<br/>
<br/>
Vdic + you ni naru= "reach the point where~"/"come to~"<br/>
<br/>
子供は自分で部屋を片付けるようになりました。<br/>
(My) child has reached the point where she cleans her room herself.<br/>
<br/>
Vneg + you ni naru= "reach the point where ~not"<br/>
<br/>
林さんはたばこを吸わないようになる。<br/>
Mr.Hayashi has reached the point where he does not smoke.<br/>
<br/>
*Vdic= Verb, dictionary form<br/>
<br/>
