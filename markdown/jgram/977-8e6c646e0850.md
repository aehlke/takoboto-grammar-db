## Meaning

the more +V(+A), the more ...

the more you read, the less you know

## Notes

### 1 — rubyhatchet

FORMATION:<br/>
Ｖ(ば form) + Ｖ(dict. form) + ほど<br/>
いＡ + ければ＊ + いＡ + ほど<br/>
＊EX: ちかい + ければ = ちかければ<br/>
なＡ + なら(ば) + なＡ + ほど

## Discussion

### 1 — Amatuka

See also standard '-ba' conditional verb form.

### 2 — dc

can this be used with an adjective?<br/>
出きるだけ早ければ、早いほどいいと思います。<br/>
= the sooner we do it the better, i think

### 3 — たか

yes ok! but this is more polite...<br/>
出来るだけ早ければ早いほうがありがたいです。<br/>
= I would be grateful if we can do it sooner rather than later

### 4 — bamboo4

In 早ければ早いほう、「出来るだけ」is redundant and not needed because that is indirectly implied.

### 5 — dc

thanks, noted, and now an example.

### 6 — bamboo4

If you say, 早ければ早いほう, you need が, but if you say 早ければ早いほど, you don't need が.<br/>

### 7 — dc

so in this case you don't use any article? は・が・を<br/>
<br/>
→　早ければ早いほど  ありがたいです

### 8 — bamboo4

That is correct, dc.
