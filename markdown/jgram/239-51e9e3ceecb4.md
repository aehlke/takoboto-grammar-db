## Meaning

if (it's) not; unless

It won't sell if it's not interesting.

## Notes

### 1 — dc

literal translation<br/>
naikoto = not thing<br/>
niha = if<br/>
<br/>
so a literal translation might be:<br/>
if (not A), then B won't happen (either)

### 2 — rubyhatchet

「ＡないことにはＢ(ない)」: A is a requirement in order to do B.<br/>
<br/>
FORMATION:<br/>
Ｖない + ことには<br/>
いＡ(minus い) + くないことには<br/>
なＡ・Ｎ + でないことには

Some of those examples do not reflect the meaning of this grammar point as a single block, but that of the separate particles "nai + koto + ni wa" which mean "at/to the matters/things that do not...". I think they are bad examples, so I will mark them as suspicious.
