## Meaning

a short period of time 我慢することです

Don\`t rest now work is almost finished.

## Notes

### 1 — tigert

<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> means [with one breath] and it is used to describe a short period of time, Usually in which something will accure. <br/>
<br/>
<br/>
休憩しないで、後一息仕事が終わりますよ。<br/>
<br/>
Don`t rest now, works almost finished.
