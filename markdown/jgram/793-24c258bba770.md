## Meaning

became a rule; been decided that; expected to; supposed to

My daughter is supposed to study abroad next year.

## Notes

### 1 — rubyhatchet

Ｖ(plain form) + ことになっている // こととなっている<br/>
Ｖない + ことになっている // こととなっている<br/>
<br/>
You can only use verbs with this grammar.

## Discussion

### 1 — Amatuka

Wouldn't <b>"It has come to be that children are prohibited from being made to work by law."</b> be a more literal translation?

### 2 — Amatuka

Hmm, I think there should be a <b>ことになる</b> grammar entry.

### 3 — bamboo4

The English translation of the first example is more like "By law, children are not supposed to be put to work."

### 4 — LittleFish

This refers to rules, social customs and regulations; in contrast to kotoninaru, which means "it has been arranged that."

### 5 — petra

<b><a href="http://jgram.org/pages/viewOne.php?tagE=kotoninatteiru#">#</a></b> 人種　is supposed to be "race" instead of "racism."

### 6 — tigert

Ex 6117 seems like it should be ことになる　instead of ことになっている. <br/>
I think it would be more natural to say, It has been decided that my daughter will study abroad next year. IE.<br/>
<br/>
娘は来年､留学することになりました．<br/>
<br/>
If you use になっている here it expresses more of a continued state, or a rule/custom.

### 8 — tigert

karekora &gt; I`m not sure whats written in the jlpt, but I have never heard the japanese used in that way. usually when ことになっている has been used in my conversations with native speakers, it is used to describe a custom, a law, or a social　rule that must be followed. I`ve never heard it used to refere to future plans. but I have heard ことになりました or ことになります used to describe plans.
