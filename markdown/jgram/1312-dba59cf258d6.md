## Meaning

to do something for someone else

I will read this to you

## Notes

### 1 — Furan

When someone is considering offering their services, they can use <b><a href="http://jgram.org:80/pages/viewOne.php?tagE=ageru">ageru</a></b>, which is usually the translation of "to give" (transitive verb here).<br/>
<br/>
See the examples below.<br/>
<br/>
Most of the time, people use it combined with the [-て] form. <br/>
<br/>
Because of the nuance it adds, it's a one-way verb to use : this form is meant to humbly express yourself to someone. <br/>
<br/>
The honorific way could be like this : <br/>
貴方の為なら、何でもいたします。<br/>
(Anata no tame nara, nan de mo itashimasu.)<br/>
I would do anything for you.<br/>
[liter. "if it is for you, I shall do anything"]<br/>
<br/>
 (it's a very basic note ; please check <b><a href="http://jgram.org:80/pages/viewOne.php?tagE=kureru">kureru</a></b> and <b><a href="http://jgram.org:80/pages/viewOne.php?tagE=morau">morau</a></b> to get a better understanding of the usage of these verbs)
