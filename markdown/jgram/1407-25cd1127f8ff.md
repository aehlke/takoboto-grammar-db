## Meaning

That means, If that's the case, etc

That means that there is no time to drink beer\!

### 1 — dc

doesnt this mean more like "_if_ that's true, then..." - ie based on preceding item.<br/>
so your ex <b><a href="http://jgram.org/pages/viewOne.php?tagE=sousuruto#">#</a></b> would be:<br/>
If thats true, then we dont have time for a drink.

### 2 — bamboo4

彼女らを should be 彼女らと. Also, "to drink a beer" should be "to drink beer."

### 3 — ninja\_k
