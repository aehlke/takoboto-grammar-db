## がたい (gatai)

Publication date as displayed: Wed, 20 Nov 2019 01:06:01 PST

[Original entry](http://www.jgram.org/pages/viewOne.php?tagE=gatai&date=2019-11-20)

<span>がたい (gatai)</span><br/><br/>
       <span><b>Meaning</b>: Vm, ‾ difficult to </span><br/>
    <strong>Example</strong>: <i>hard to understand</i><br/>
<br/>
     [ <a href="http://www.jgram.org/pages/viewOne.php?tagE=gatai">View this entry online</a> ]<br/>
<br/>
<strong><strong>   Notes:  </strong></strong><br/>Implies that something is so difficult that it  <b>can't</b> be done. For something that's just really difficult to do it's better to use 〜にくい or 〜づらい.<br/>
<br/>
Also, the verbs it's used as a pair with are pretty limited. Here are a few more:<br/>
賛成しがたい, but 反対しがたい you absolutely <b>can't</b> say.<br/>
表現しがたい<br/>
考えがたい<br/>
動かしがたい事実<br/>
受け入れがたい<br/>

<strong><strong>   Comments:  </strong></strong><br/><ul>
<li>First example : Lit. "The beauty of the scenery is hard to express completely." (contributor: <i>Amatuka</i>)<br/>
<li>Kanji 難い (contributor: <i>Amatuka</i>)<br/>
<li>Formed from Verb -masu base + gatai<br/>
Vm - Verb -masu base (contributor: <i>Amatuka</i>)<br/>
<li>I've noticed that the verbs that tend to use GATAI　are pretty scarce so is there a time when this grammar point should be used or can it be used for anything without any problems? (contributor: <i>Exrulez</i>)<br/>
<li>By definition, 難い means "difficult" so that it is associated with things that has problems to begin with.<br/>
 (contributor: <i>bamboo4</i>)<br/>
<li>Would something like　「今夜早く暗くなって道が見難い」be something you say or write (or be quite possibly neither)? (contributor: <i>Leslie</i>)<br/>
<li>First of all, 見難い is read as minikui here. This is used in conversation and writing. But in writing, 今夜は is better in this sentence. <br/>
If you meant "something-gagai", we use it in both cases as well but the sentence sounds rather formal in speaking. (contributor: <i>anon</i>)<br/>
<li>Common examples:<br/>
<br/>

許しがたい<br/>
耐えがたい<br/>
得がたい<br/>
信じがたい<br/>
表しがたい<br/>
 (contributor: <i>Arma</i>)<br/>
<li>The word pattern "...し難い" can produce many examples.<br/>
 (contributor: <i>bamboo4</i>)<br/>
<li>See also "nikui"? (contributor: <i>theWonderer</i>)<br/>
<li>〜がたい suggests that s.th. is extremely difficult or nearly impossible to do. It is often used  with words such as shinjiru (to believe), taeru (to endure),rikaisuru (to understand), eru (to obtain), suteru (to discard), and hanareru (to be seperated from), and refers to mental activity instead of actual deeds. For example, sutegatai implies that one finds it difficult to part with a memory or s.th. one is attached to. (contributor: <i>angelitosh2004</i>)<br/>
