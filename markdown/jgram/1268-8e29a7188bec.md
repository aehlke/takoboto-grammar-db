## Meaning

in order to

in order to be on time

## Notes

### 1 — anon

there are a few ways to express the intention to do something, which seem very similar at first. but:<br/>
<br/>
-youni is used with the potential or negative form of a verb.<br/>
<br/>
　yoku kikoeru youni .. = to be able to hear better<br/>
　wasurenai you ni = in order not to forget<br/>
　dekiru yooni = so that I will be able to do<br/>
<br/>
<br/>
-<b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> is usually just the plain form<br/>
　kau tameni = in order to buy<br/>
　kiku tameni = in order to hear<br/>

### 2 — dc

see <b><a href="http://jgram.org/pages/viewOne.php?tagE="></a></b> for similar items and comparisons.

### 3 — Ayumi

Also means "like" or "as"<br/>
<br/>
Watashi you ni hashiru. (Run like me, to run like me)

## Discussion

### 1 — Amatuka

As seen in 'ようお願い申し上げます' the に may be omitted in some usages.  <br/>
BTW, that would appear to be a very polite sentence.

### 2 — Amatuka

Formed from 'verb + you ni'<br/>
<br/>
V = verb

### 3 — Amatuka

When used at the end of a sentence it usually indicates a wish, prayer or hope etc.

### 4 — dc

I was told that  verbs are not as comfortable in this construct, but not sure why. eg<br/>
計算するように、市場データを調べておきました<br/>
In order to do a calculation, I researched market data<br/>

### 5 — dc

計算するように<br/>
is a different expression. It sounds like <br/>
計算するかのように <br/>
= like a calculation, metaphorically speaking<br/>
<br/>
so you should use <br/>
計算するために <br/>
in this case. It is different from 間に合うように<br/>
<br/>
← can someone clarify this explanation?

### 6 — Miki

The Japanese of ex 3 is not matched to English. <br/>
この度の流出したデータを入手された方は→この度データを入力された方は

### 7 — Miki

ex 1 J should be 間に合うように not 間に合うするように.

### 8 — Miki

As for 計算するように、市場データを調べておきました。I think it is just not natural in the context. :( Others will be able to help.<br/>

### 9 — bamboo4

Only 計算するように I can think of lis that of an instruction or order = 間違いなく計算するようにしてください (see to it that you perform the calculations without any error.)<br/>

### 10 — blabby

ように is used for non-volitional verbs for example できる、わかる、見える、聞こえる、起きられる.  It is also used for the negative form of verbs 〜ないように.  Otherwise ために is used. However I don't think it is always this simple. Some verbs can be volitional and non-volitional.
