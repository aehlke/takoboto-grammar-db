## Meaning

especially because (non-intuitive nuance) 常識に反する理由だが、その理由を特に言いたい時に使う表現

When it snows, I really miss my mother.

## Examples

### 5726 — srobertson

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ雪だからこそ、うちにいたくない。雪の日にうちにいるのは寂しすぎる。">
				雪<strong>だからこそ</strong>、うちにいたくない。雪の日にうちにいるのは寂しすぎる。<strong></strong></a> <br/>
		I don't want to stay at home, 
		<strong>especially since </strong>
		  it's snowing. On snowy days, being at home is too lonely.

### 5727 — srobertson

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ頭がいいと思っているからこそ">
				頭がいいと思っている<strong>からこそ</strong><strong></strong>、厳しくしつけるのです。</a> <br/>
		It's 
		<strong>precisely because </strong>
		  I think you've got brains that I'm bringing you up so strictly.

### 5728 — srobertson

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ実は、知らない人ばかりだったからこそ、言いにくいことも言うことができたのだ。">
				実は、知らない人ばかりだった<strong>からこそ</strong>、言いにくいことも言うことができたのだ。<strong></strong></a> <br/>
		Actually, it was 
		<strong>especially_because </strong>
		  they were all people I didn't know that I was able to say things I usually find difficult to say.

### 6503 — aoiaki

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ手伝ってくれたからこそ、仕事が早く出来ましたよ。">
				手伝ってくれた<strong>からこそ</strong>、仕事が早く出来ましたよ。<strong></strong></a> <br/>
		I was able to do this work quickly, 
		<strong>(especially) because of </strong>
		  all your help.
