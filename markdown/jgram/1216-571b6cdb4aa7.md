### 5 — yookoso

I saw the following explanation of the difference between kara and node on a mailing list today: <br/>
<br/>
The conjunction "kara" and "node" both express reason or cause. While "kara" is used for reason or cause of a speaker's volition, opinion and so on, "node" is for existing (existed) action or situation.<br/>
- Kino wa samukatta node uchi ni imashita. Since it was cold, I stayed home.<br/>
- Atama ga itakatta node gakkou o yasunda. Since I had a headache, I didn't go to school. <br/>
- Totemo shizukadatta node yoku nemuremashita. Since it was very quiet, I could sleep well.<br/>
- Yoku benkyou shita node shiken ni goukaku shita. Since I studied hard, I passed the examination.<br/>
<br/>
The sentences expressing personal judgment such as speculation, suggestion, intention, request, opinion, volition, invitation, and so forth must take "kara."<br/>
- Kono kawa wa kitanai kara tabun sakana wa inai deshou. Since this river is polluted, there is probably no fish. <br/>
- Mou osoi kara hayaku nenasai. Go to bed, since it is getting late.<br/>
- Kono hon wa totemo omoshiroi kara yonda hou ga ii. This book is very interesting, so you'd better to read it.<br/>
- Kono kuruma wa furui kara atarashi kuruma ga hoshii desu. This car is old, so I want a new car.<br/>
<br/>
While "kara" focuses more on the reason, "node" focuses more on the resulting effect. This is why the "kara" clause is used independently more often than "node".<br/>
- Doushite okureta no. Why were you late?<br/>
- Densha ni nori okureta kara. Because I missed the train.<br/>
<br/>
"Kara" can be immediately followed by "~ desu."<br/>
- Atama ga itakatta kara desu. Because I had a headache. (OK)<br/>
- Atama ga itakatta node desu. Because I had a headache. (Not OK = Wrong)<br/>
<br/>
