## Meaning

if ~ any more than this

If it rains any more...

## Examples

### 3002 — dc

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJこれ以上雨が">
<strong>これ以上</strong>雨が<strong>降れば</strong>、川が氾濫してしまう</a> <br/>
		If it rains 
		<strong>any more than this </strong>
		the river will flood.

### 3008 — bamboo4

<a href="http://www.csse.monash.edu.au/~jwb/cgi-bin/wwwjdic.cgi?9MHJ皆さんからお褒めの言葉を頂きこれ以上の光栄はございません。">
				皆さんからお褒めの言葉を頂き<strong>これ以上</strong>の光栄はございません。<strong></strong></a> <br/>
		Having received many kind compliments from all of you, I cannot feel 
		<strong>any more </strong>
		honored than this.
