## Meaning

looks like or seems like

seems it will rain

## Notes

### 1 — dc

There are a number of ways of relating second hand info. Generally in increasing order of certainty:<br/>
<br/>
<b><a href="http://jgram.org:80/pages/viewOne.php?tagE=darou">darou</a></b>  - perhaps (just a guess)<br/>
明日雨が降るだろう<br/>
= it will probably rain tomorrow<br/>
<br/>
<b><a href="http://jgram.org:80/pages/viewOne.php?tagE=rashii">rashii</a></b> - i heard<br/>
明日雨が降るらしい<br/>
= (from what i heard) it will rain tomorrow<br/>
<br/>
<b><a href="http://jgram.org:80/pages/viewOne.php?tagE=sou">sou</a></b>  - seems<br/>
雨が降りそうだ<br/>
= (it looks like) its going to rain<br/>
<br/>
<b><a href="http://jgram.org:80/pages/viewOne.php?tagE=sou-2">sou-2</a></b> - i heard<br/>
雨が降るそうだ<br/>
= I heard it will rain<br/>
<br/>
<b><a href="http://jgram.org:80/pages/viewOne.php?tagE=you">you</a></b>  - it seems<br/>
空を見ると雨が降るようだ。<br/>
= (From the look of the sky and based on my judgement) it seems like it will rain<br/>
<br/>
<b><a href="http://jgram.org:80/pages/viewOne.php?tagE=mitai">mitai</a></b> - looks like<br/>
彼はやりたいみたいですね<br/>
= Looks like he wants to do it<br/>
this seems much more casual, younger

### 2 — bamboo4

[sou -2]<br/>
雨が降るときいています<br/>
= I heard it will rain<br/>

## Discussion

### 1 — jacobhart

The 'sou-2' example should say 雨が降るそうだ。

### 2 — dc

so these two are ..so.. similar:<br/>
<br/>
雨が降りそう - seems like<br/>
(verb-masu stem) 降ります<br/>
<br/>
雨が降るそうだ  - i heard<br/>
(verb-plain + sou)
