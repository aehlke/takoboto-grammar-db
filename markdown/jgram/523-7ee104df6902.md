Verb (dictionary form) + <b>まえに</b><br/>
Noun + <b>のまえに</b><br/>
<br/>
(いちだん)  <br/>

<br/>
(ごだん)<br/>
行く<strong>まえに</strong> (いく<strong>まえに</strong>)Before going<br/>
<br/>
