# ~直す

Source: [Takoboto #1685](https://takoboto.jp/bunpo/1685/)

JLPT: unclassified  
Credits: jmadsen

Other forms: ~なおす

## Meaning

to do something again, hoping to improve it

This essay is terrible\! Please rewrite it (書き直す)

Meaning credits: jmadsen

## Examples

### Example 8749

**第一回目試験を落第したから、受け直すつもりだよ。**dai ikkai me shiken wo rakudai shita kara, uke-naosu tsumori da yo.

だいいちかいめしけんをらくだいしたから、うけなおすつもりだよ。

en: **Since (I) failed the test the first time, (I'm) planning on re-taking it.**
