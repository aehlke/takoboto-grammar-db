## Discussion

### Comment 1 — anon

there are a few ways to express the intention to do something, which seem very similar at first. but:<br/><br/>-youni is used with the potential or negative form of a verb.<br/><br/>　yoku kikoeru youni .. = to be able to hear better<br/>　wasurenai you ni = in order not to forget<br/>　dekiru yooni = so that I will be able to do<br/><br/><br/>-[tameni] is usually just the plain form<br/>　kau tameni = in order to buy<br/> kiku tameni = in order to hear

### Comment 2 — dc

see [basis-of-action-group] for similar items and comparisons.

### Comment 3 — Ayumi

Also means "like" or "as"<br/><br/>Watashi you ni hashiru. (Run like me, to run like me)

### Comment 4 — KotatsuSama

I don't know what a volitional form is... but you-ni also means (like doing-)<br/>計算ように次の作動を考えた。<br/>Like calculating, he thought out his next move.

### Comment 5 — bamboo4

計算ように次の作動を考えた should be あたかも計算するように次の動作を考えた

### Comment 6 — dc

I was told that verbs are not as comfortable in this construct, but not sure why. eg<br/>計算するように、市場データを調べておきました<br/>In order to do a calculation, I researched market data

### Comment 7 — dc

計算するように<br/>is a different expression. It sounds like <br/>計算するかのように <br/>= like a calculation, metaphorically speaking<br/><br/>so you should use <br/>計算するために <br/>in this case. It is different from 間に合うように<br/><br/>← can someone clarify this explanation?

### Comment 8 — Miki

The Japanese of ex 3 is not matched to English. <br/>この度の流出したデータを入手された方は→この度データを入力された方は

### Comment 9 — bamboo4

Only 計算するように I can think of lis that of an instruction or order = 間違いなく計算するようにしてください (see to it that you perform the calculations without any error.)

### Comment 10 — Miki

ex 1 J should be 間に合うように not 間に合うするように.

### Comment 11 — Miki

As for 計算するように、市場データを調べておきました。I think it is just not natural in the context. :( Others will be able to help.

### Comment 12 — blabby

ように is used for non-volitional verbs for example できる、わかる、見える、聞こえる、起きられる. It is also used for the negative form of verbs 〜ないように. Otherwise ために is used. However I don't think it is always this simple. Some verbs can be volitional and non-volitional.

### Comment 15 — bamboo4

As far as I know, ように can be used for both volitional and non-volitional verbs.

### Comment 16 — Amatuka
