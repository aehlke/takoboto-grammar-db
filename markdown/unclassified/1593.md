## Meaning

wish

I wish today's weather was as nice as yesterday's

Meaning credits: ziaz

## See also

- [のに](../n2/552.md)

## Examples

### Example 6072

今日の天気が昨日のような天気だったら良かった**のに**

きょうのてんきがきのうのようなてんきだったらよかったのに

en: **I wish**  today's weather had been as nice as yesterday's.

Credits: ziaz

### Example 8383

雨さえやめばいい**のに**なあ。

あめさえやめばいいのになあ。

en: If only it would stop raining\!

Credits: karekano
