## Meaning

as soon/early as possible

I'd like to meet as soon as possible

Meaning credits: dc

## See also

- [だけ](../n5/249.md)

## Examples

### Example 4956

**できるだけ早く**参ります。

できるだけはやくまいります。

en: I'll come **as soon as I can.**

Credits: Miki

### Example 4957

この本は**できるだけ早く**返してくれ。

このほんはできるだけはやくかえしてくれ。

en: Return this book **as soon as you can.**

Credits: Miki

### Example 4958

**できるだけ早く**起きなさい。

できるだけはやくおきなさい。

en: Get up **as early as you can.**

Credits: Miki

### Example 4959

**できるだけ速く**走ったので、友人に追いつけた。

できるだけはやくはしったので、ゆうじんにおいつけた。

en: Running **as fast as I could,** I was able to catch up with my friend.

Credits: Miki

### Example 4975

彼は**できるだけ長く**生きたいと思っている。

かれはできるだけながくいきたいとおもっている。

en: He wants to live **as long as he can.**

Credits: Miki

### Example 5707

好きな**だけ**、食べてください。

すきなだけ、たべてください。

en: Please eat **as much as** you like.

Credits: blabby

## Discussion

### Comment 1 — dc

dekirudake + adverb means "as much as (adverb)".<br/>its used as an almost set phrase with 'hayaku':early/fast.<br/>dekirudake hayaku: as quickly/soon/early as possible.

### Comment 2 — dc

is this used with the leading verb being a potential?<br/>会えるだけ早く<br/>meet as soon as possible<br/><br/>作れるだけ早く<br/>make as soon as possible<br/><br/>食べられるだけ早く<br/>eat as quickly as possible

### Comment 3 — dc

can it be used with negatives?<br/><br/>できるだけ遅く<br/>as slowly/late as possible?

### Comment 4 — Miki

If you use the verb twice like this, it is possible. 会えるだけ早く会う。

### Comment 5 — Miki
