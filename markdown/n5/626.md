## Meaning

(location marker, time marker, direction marker)

There's a dog in that car.

## Discussion

### Comment 1 — Sakuratree

Ni can mark time such as:<br/><br/>At 3:00 pm, I studied French.<br/>午後三時間にフランス語を勉強しました。<br/><br/>An object location marker:<br/><br/>In Tokyo, there is the Tokyo Tower.<br/>東京に東京タワーにあります。<br/><br/>And direction:<br/><br/>I'm going to the store tomorrow.<br/>明日店に行きます。

### Comment 2 — Amatuka

There are a few places where に can't be used.<br/>×友だちにのプレゼント [tomodachi ni no purezento] BAD<br/>○友だちへのプレゼント [tomodachi he no purezento] GOOD<br/><br/>And some where only に can be used<br/>事務所にパソコンがある [jimusho ni pasokon ga aru]

### Comment 5 — suya

に can also be used when going somewhere in order to do something.<br/>For example,<br/>「図書館で勉強するに行った。」<br/>"I went to the library to study."<br/>に can be basically translated to "to (location)". In the above sentence, there are two "to" in it. The first is "to (location)" type: I went TO the library. The second "to" is "in order to" or shortened to "to (do something)": went TO study.<br/><br/>A simpler example using the "in order to" type is:<br/>「勉強するに行った。」<br/>"I went to study."<br/>The verb before the に must be in dictionary form.<br/><br/>This makes it easy to connect verbs and you don't have to use から. What I mean is,"図書館に行きましたから、べんきょうしたいでした。" which is really long.<br/><br/>Sorry if that doesn't make sense, but I didn't see anyone else commenting on that particular use so please correct me if I'm wrong.

### Comment 6 — beno

@suya It would be 勉強しに行った。The verb is masu-stem not dictionary form.

### Comment 7 — Vero

@Vinod<br/>I think it can either be 「東京に東京タワーがあります」to state the fact that the Tokyo Tower is in Tokyo or 「東京タワーは東京にあります」to tell that the Tokyo tower is located in Tokyo． The second sentence emphasizes on the location.
