## Meaning

en: This is **also** mine.

## Discussion

### Comment 1 — Sakuratree

Just like how in English, we say, "me too!" Japanese uses the particle も<br/><br/>It rained today too.<br/>今日も雨が降っていました。

### Comment 2 — Amatuka

も replaces は in the first example sentence.<br/>A previous [something] being mine is implied.<br/>(e.g. 'あれは私のです。ええと、これも私のです。'<br/>That (over there) is mine. Erm, and this is also mine. )
