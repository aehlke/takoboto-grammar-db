## Examples

### Example 631

フレッド君**の**車はどこにありますか。

フレッドくんのくるまはどこにありますか。

en: Where is Fred **'s** car?

Credits: Amatuka

### Example 632

フレッド君**の**ですか。

フレッドくんのですか。

en: (Is this) Fred **'s** ?

Credits: Amatuka

### Example 5327

「これは誰**の**ペン？」「私**の**。」「kore wa dare no pen?」「watashi no。」

「これはだれのペン？」「わたしの。」「。」

en: **"Whose**  pen is this?" **"Mine."**

Credits: Miki

### Example 8637

リリー**の**靴はどこにあるか知りません。

リリーのくつはどこにあるかしりません。

en: I don't know where Lilly's shoes are.

Credits: Sakuratree

### Example 8806

お前**の**せいだぞ！

おまえのせいだぞ！

en: It's **your**  freaking fault\!

Credits: 貴博

## Discussion

### Comment 1 — Sakuratree

no (の) can be used in Japanese in so many ways that it's amazing.<br/><br/>One way is to show ownership:<br/><br/>This is my room.<br/>これは私の部屋です。<br/><br/>Since in Japanese, no plurals exist this particle can act like an 's <br/><br/>So:<br/><br/>Kelly's car is very old.<br/>ケリーの車はとても古いです。

### Comment 2 — Amatuka

Note how the object may be omitted if it is understood from context.

### Comment 3 — Amatuka

の can be used in other ways which you will come across later in Japanese study.

It's my understanding that 'ka' is usually left out in casual speech, where questions can be implied through intonation, but you should always use 'ka' in writing, of course.
