## Discussion

### Comment 1 — rubyhatchet

Ｖ(plain form) + 際<br/>Ｎ + の + 際<br/>Ｎに際して <br/>この/その/あの際<br/><br/>Be careful with the verb conjugation before 際. Only use Ｖinf・nonpast or Ｖinf・past, which indicate incompletion or completion, respectively. For example, 買う/買った + 際(に).<br/><br/>Also, Ｎに際して is more formal than Ｎ + の + 際. Ｎに際して must be used when speaking about a very, very special occasion.<br/><br/>One final note: 〜際に is a formal expression that is often used with Sino-Japanese words. In sentences in which neither a Sino-Japanese verb/noun nor a honorific-polite verb is used, 際に is unacceptable.
