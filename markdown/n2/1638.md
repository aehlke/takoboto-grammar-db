## Meaning

Not only not X, but also not Y. Both can be good things, or both bad.

Not only is that route not difficult to navigate, (but) it is also not bumpy.

ja: ないだけでなく

Meaning credits: makara

## Examples

### Example 6550

彼は会社へ来ても**仕事をしないばかりか,**女性社員としゃべってばかりいる。

かれはかいしゃへきてもしごとをしないばかりかじょせいしゃいんとしゃべってばかりいる。

en: Although he has come to the company, **not only does he not work,** but about all he's doing is chatting with the female employees

Credits: makara

### Example 6810

彼女は**歌をよく歌えないばかりか**ピアノも弾けないなあ。

かのじょはうたをよくうたえないばかりかピアノもひけないなあ。

en: Not only is she **not able to sing songs well,** but she can't play the piano, either.

Credits: anna.kendall

### Example 8699

**このペーパータオルはお値段が高くないばかりか**何度も使うことができ、重宝します。

このペーパータオルはおねだんがたかくないばかりかなんどもつかうことができ、ちょうほうします。

en: **Not only is this paper towel not expensive,** but I can use it a number of times, and it is handy.

Credits: american57

## Discussion

### Comment 1 — american57

Because this is "...nai bakari ka", the first clause must be translated in the negative, not the affirmative. "Not only is it not attractive, it isn't even safe." "Not only is it not expensive, (but) it doesn't take up much space, either!" A close relative is "dake de naku," which tends to have the first clause in the affirmative.
