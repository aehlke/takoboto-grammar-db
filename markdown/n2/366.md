## Meaning

no need to

There's no need to be insulting, you know\!

ja: 〜しなくても　いい

Meaning credits: dc

## Formation

- Verb dictionary form + ことはない

## Examples

### Example 422

ただの風邪ですから、心配する**ことはありません**

ただのかぜですから、しんぱいすることはありません

en: Its just a common cold, so **there's no need to** worry.

Credits: dc

### Example 4660

この世に思いわずらう**ことはない。**

このよにおもいわずらうことはない。

en: I **don't** have a care in the world.

Credits: Miki

### Example 5820

時間は十分あるから急ぐ**ことはない**。

じかんはじゅうぶんあるからいそぐことはない。

en: There is **no need to** hurry as we have plenty of time.

Credits: Meghana

### Example 6120

ちょっと待たされただけで、なにもそんなに怒る**ことはない**でしょう。

ちょっとまたされただけで、なにもそんなにおこることはないでしょう。

en: You only had to wait a little bit, so **there's no need to** get so upset.

Credits: rubyhatchet

### Example 6623

君があやまる**ことはない**よ。

きみがあやまることはないよ。

en: There is no need for you to apologize.

Credits: hana
