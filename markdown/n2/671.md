Other forms: いじょう

## Meaning

Vru, since; now that; once; as long as

as long as you're here, we may as well have fun

Meaning credits: dc

## Formation

- Verb past form + 以上 + (は)
- Verb dictionary form + 以上 + (は)
- な-adjective + である + 以上 + (は)
- Noun + である + 以上 + (は)

## Discussion

### Comment 1 — Amatuka

Formed from Vru + ijou.<br/>Also from 'continuing action' e.g. 使ってる以上<br/>Vru = dictionary form. （〜る for ichidan / regular group 2 verbs)

### Comment 2 — Miki

以上は in context can be replaced with からには.

### Comment 3 — dc

is this the same as [kagiri] ?<br/><br/>学生である限り、勉強します<br/>学生である以上、勉強します<br/><br/>are identical in meaning/nuance?
