# 上で

Other forms: じょうで

## Meaning

In, On

X-windows doesn't run on Virtual-PC.

Meaning credits: Amatuka

## See also

- [上で](../n2/124.md)

## Examples

### Example 477

Virtual PC**じょうで**、 Xwindowsが立ち上がりません。.

じ、がたちあがりません。

en: X windows doesn't start up **on** Virtual PC.

Credits: Amatuka

### Example 4599

いろいろな動物が地球**上**から姿を消した。

いろいろなどうぶつがちきゅうじょうからすがたをけした。

en: Many kinds of animals have vanished from the earth.

Credits: Miki

### Example 4602

空気が無ければ、我々は地球**上で**生きられないだろう。

くうきがなければ、われわれはちきゅうじょうでいきられないだろう。

en: If it were not for air, we could not live on the earth.

Credits: Miki
