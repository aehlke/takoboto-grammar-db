# ことになる

Source: [Takoboto #913](https://takoboto.jp/bunpo/913/)  
Label: kotoninaru  
JLPT: N2  
Credits: Amatuka  
Retrieved: 2026-10-03T05:38:39+00:00

## Meaning

To be decided, to be arranged

It has been decided I will go to new york

Meaning credits: Amatuka

## Examples

### Example 787

このレポート、いずれやる**ことになる**のだから、今すぐやろう。

このレポート、いずれやることになるのだから、いますぐやろう。

en: At anyrate this report has **got to be** done at some point so \[might as well\] do it now.

Credits: Amatuka

### Example 919

すぐに使う**ことになる**システム。

すぐにつかうことになるシステム。

en: The system you're **bound to** use right away.

Credits: Amatuka

### Example 1158

私は来年大阪へ転勤する**ことになった**

わたしはらいねんおおさかへてんきんすることになった

en: **It has been decided that** I will transfer to Osaka next year

Credits: dc

### Example 3704

あすで１週間雨が降りつづく**ことになる**。

あすで１しゅうかんうがおりつづくことになる。

en: It will have been raining for a week by tomorrow.

Credits: dbx

### Example 3708

あなたにはこの工場の女子職員の管理をしていただく**ことになる**でしょう。

あなたにはこのこうじょうのじょししょくいんのかんりをしていただくことになるでしょう。

en: You'll be in charge of the girl working in this factory.

Credits: dbx

### Example 7835

主人が仕事で東京にいく**ことになった**。

しゅじんがしごとでとうきょうにいくことになった。

en: **It has been decided** that my husband will go to Tokyo for professional reasons.

Credits: Nihonjin

### Example 7836

留学する**ことになりました**。

りゅうがくすることになりました。

en: **It has been arranged** that I will study abroad.

Credits: Nihonjin
