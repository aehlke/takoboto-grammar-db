# まま

Source: [Takoboto #1621](https://takoboto.jp/bunpo/1621/)  
Label: mama  
JLPT: N3  
Credits: Nihonjin

Other forms: 儘

## Meaning

as it is, leave as it is, (remain) unchanged

I'll leave this place as it is.

Meaning credits: Nihonjin

## Formation

- Verb た-form + まま
- Verb ない-form + まま
- い-adjective + まま
- な-adjective + な + まま
- Noun + の + まま

## Examples

### Example 6451

２つの問題が未解決の**まま**であった。

ふたつのもんだいがみかいけつのままであった。

en: Two problems remained unsolved.

Credits: Nihonjin

### Example 6452

この家はこの**まま**にしておきたい。

このいえはこのままにしておきたい。

en: I like this house as it is.

Credits: Nihonjin

### Example 6453

この家は今の**まま**では売れないだろう。

このいえはいまのままではうれないだろう。

en: This house will not sell as it stands.

Credits: Nihonjin

### Example 6454

この自転車は今月の初めからここに置かれた**まま**だ。

このじてんしゃはこんげつのはじめからここにおかれたままだ。

en: This bicycle has been left here since the beginning of this month.

Credits: Nihonjin

### Example 6455

この窓は一ヶ月割れた**まま**になっている。

このまどはいちかげつわれたままになっている。

en: This window has been broken for a month.

Credits: Nihonjin

### Example 6456

しばらくこの**まま**お待ち下さい。

しばらくこのままおまちください。

en: Hold on for a while, please.

Credits: Nihonjin

### Example 6457

すべて私がそこを去った時の**まま**でした。

すべてわたしがそこをさったときのままでした。

en: Everything was as it had been when I left there.

Credits: Nihonjin

### Example 8787

この家は今年の始めから汚い**まま**だ。

このいえはことしのはじめからきたないままだ。

en: This house has been dirty since the beginning of this year.

Credits: バラティ
