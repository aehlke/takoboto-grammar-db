## Meaning

by \_\_\[day, date, time, etc.\]\_\_

Turn in the report by Friday.

Meaning credits: Chad

## Examples

### Example 8119

明日**までに**それを済ませてしまうべきです。

あしたまでにそれをすませてしまうべきです。

en: You ought to have done it by tomorrow.

Credits: karekano

### Example 8670

お昼**までに**戻らないといけない。

おひるまでにもどらないといけない。

en: (I) need to be back by noon.

Credits: mdchachi

### Example 8849

書類を夜**までに**ださなければなりません。

しょるいをよるまでにださなければなりません。

en: Document must be submitted **by**  evening.

## Discussion

### Comment 1 — Chad

までに is giving a time limit which must be kept. Finishing the required action before is also fine.<br/><br/>In opposition まで denotes an action etc. which continues until the given time and does not finish before.

### Comment 2 — american57

Cannot be used with continuous action/state, such as "aru/iru". See made de for subtle difference.
