## Meaning

assume, regard X as ~ , suppose

if we assume that n=1

Meaning credits: dc

## See also

- [としたら、とすれば、とすると](../n2/297.md)

## Examples

### Example 568

日本へ行く**とすれば**

にほんへいくとすれば

en: **If we assume that** we go to japan

Credits: dc

### Example 815

温度は一定である**とする**。

おんどはいっていであるとする。

en: **We assume that** temperature is constant.

Credits: Amatuka

### Example 4191

あなたが立派な世界市民になろう**とする**なら、偏見は持たないように努力すべきである。

あなたがりっぱなせかいしみんになろうとするなら、へんけんはもたないようにどりょくすべきである。

en: If you are to be a good world citizen, you should try to be free of any prejudices.

Credits: Miki

### Example 6405

私たちは みな、 人生に おいて 成功を 収めよう**とする**が、成功するのは、きわめて 数少ない人たちである。

わたしたちはみな、じんせいにおいてせいこうをおさめようとするが、せいこうするのは、きわめてかずすくないひとたちである。

en: We all try hard to make the grade in life, but only a few succeed.

Credits: rolando

### Example 6406

進んで学ぼう**とする**気の無い物には教える甲斐がない。

すすんでまなぼうとするきのないものにはおしえるかいがない。

en: One who is not willing to learn is not worth teaching.

Credits: rolando

### Example 6407

歩こう**とする**とここがズキンとします。

あるこうとするとここがズキンとします。

en: When I try to walk, I get an awful pain here.

Credits: rolando

### Example 6408

労働者たちにはもっと働こう**とする**刺激がなにもない。

ろうどうしゃたちにはもっとはたらこうとするしげきがなにもない。

en: The workers have no incentive to work harder.

Credits: rolando
