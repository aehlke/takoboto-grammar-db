Other forms: -かた

## Meaning

how to \_\_\_\_\_, way to \_\_\_\_\_,

teach me how to write this kanji

Meaning credits: pedro\_cristian

## Formation

- ます stem + 方

## Examples

### Example 7444

私は英語の手紙の書き方を知っています。

わたしはえいごのてがみのかきかたをしっています。

en: I know how to write a letter in English.

Credits: pedro\_cristian

### Example 7769

この漢字の読み方を教えてください。

このかんじのよみかたをおしえてください。

en: Please teach me how to read this kanji.

Credits: jaykun

### Example 7774

いろいろな人の考え方を見出すのが好きです。

いろいろなひとのかんがえかたをみいだすのがすきです。

en: I like to discover various people's way of thinking.

Credits: kitakaze

### Example 8869

このゲームのやり方が、まだわからない

このゲームのやりかたが、まだわからない

en: I don't know yet how to play this game
