# て形+ある (て在る・て有る)

Source: [Takoboto #784](https://takoboto.jp/bunpo/784/)  
Label: tearu  
JLPT: N3  
Credits: Amatuka  
Retrieved: 2026-10-03T05:34:56+00:00

Other forms: 〜てある

## Meaning

Vte something has been purposely put into a state

The window has been closed.

Meaning credits: Amatuka

## Discussion

### Comment 1 — kurisutofu

てある only combines with transitive verbs, never intransitive. <br/>The result of transitive + てある is an intransitive itself.<br/><br/>窓が開いている -&gt; The window is open. (no agent or reason implied)<br/><br/>窓が開けてある -&gt; The window is open (because someone opened it).

### Comment 2 — bi-ru

Note that tearu only combines with transitive verbs, never intransitive. The result of transitive + tearu is an intransitive itself.

### Comment 3 — Amatuka

Compare <br/>窓が開いている。[mado ga hiraiteiru] <br/>The window is open.<br/>窓が開けてある。[mado ga aketearu]<br/>The window has been opened.

### Comment 6 — Tenorikuma

Amatuka is wrong on pronunciation.<br/><br/>窓が開いている -&gt; まどがあいている<br/><br/>As Bi-ru notes, the ている form is resultative for intransitive verbs, but the てある form lets you take a transitive verb and do the same thing.<br/><br/>窓が開いている -&gt; The window is open. (no agent or reason implied)<br/><br/>窓が開けてある -&gt; The window is open (because someone opened it).

### Comment 7 — tigert

Amatuka`s pronunciation isn`t wrong. 開く can be pronounced あく or ひらく they both mean the same thing. but あく is used for things that swing open and ひらく is used for things that slide open. IE sliding doors, windows, etc...
