## Meaning

Easy to V

A beautiful woman is easy to fall in love with / 美女は惚れやすい。

ja: 〜が使ってる動詞をする場合が簡単だと言う意味です

Meaning credits: tigert

## Formation

- Verb ます stem + やすい

## Examples

### Example 6601

雨がよく降ってる日が　家の中に遊び**やすい**です｡

あめがよくふってるひがいえのなかにあそびやすいです

en: Its **easy to** play inside on rainy days.

Credits: tigert

### Example 6602

もしかしたら日本語で毎日、読んだり、書いたりしたら、日本語が分かり**やすく**なると思います。

もしかしたらにほんごでまいにち、よんだり、かいたりしたら、にほんごがわかりやすくなるとおもいます。

en: If you do things like read and write in Japanese every day, Japanese will become **easy to** understand.

Credits: tigert

### Example 6863

かいだんがぬれています。すべり**やすい**ので、ちゅういしてくたさい。

かいだんがぬれています。すべりやすいので、ち。

en: The stairs are wet. They are slippery **(easy to** slip), so please be careful.

Credits: 赤毛

### Example 6861

このくつはあのくつよりはき**やすい**です。

このくつはあのくつよりはきやすいです。

en: These shoes here are **easier to** put on than the ones over there.

Credits: 赤毛

### Example 6862

このガラスの人形は壊れ**易い**ので、触らないでください。

このガラスのにんぎょうはこわれやすいので、さわらないでください。

en: As this glass doll break **easily,** please don't touch.

Credits: 赤毛

### Example 6864

このもんだいはまちがえ**やすい**。

このもんだいはまちがえやすい。

en: This question is **easy to** err.

Credits: 赤毛

### Example 6865

東京は生活し**やすい**ところだと思いますか。

とうきょうはせいかつしやすいところだとおもいますか。

en: Do you think Tokyo is a place where it is **easy to** live?

Credits: 赤毛

### Example 6866

このペンは書き**やすい**ですね。

このペンはかきやすいですね。

en: This pen is **easy to** write with, isn't it?

Credits: 赤毛
