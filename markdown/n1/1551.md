# ならいざ知らず

Source: [Takoboto #1551](https://takoboto.jp/bunpo/1551/)  
Label: naraizashirazu  
JLPT: N1  
Credits: blabby

Other forms: ならいざしらず

## Meaning

I'm not sure if it is \[possible/so\] but...

It's possible that an expert could do this but there is no way I can do it.

Meaning credits: blabby

## See also

- [ならともかく](../n1/1554.md)

## Examples

### Example 5780

辞書がある**ならいざ知らず**、何もなくてはこの文章はとても読めるものではない。

じしょがあるならいざしらず、なにもなくてはこのぶんしょうはとてもよめるものではない。

en: **Maybe it would be possible** if I had a dictionary, but with nothing, it is by no means easy to read.

Credits: blabby

### Example 5781

専門家**ならいざ知らず**、素人ではこの化学品を作ることができない。

せんもんかならいざしらず、しろうとではこのかがくひんをつくることができない。

en: Maybe it's possible for an expert, but a beginner can't make this chemical.

Credits: blabby

### Example 6971

他の人**ならいざしらず**、私はそんなことができない。

たのひとならいざしらず、わたしはそんなことができない。

en: **Maybe it's possible** for someone, **but** I can't do that

Credits: amenya

### Comment 3 — 誠

ex#5780 ものではない means : " shouldn't". So,I feel that it may be わけがない (impossible, by no means) or ことができない

Therefore I stand by my translation.
